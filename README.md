## Sobre o projeto

O projeto consiste no desenvolvimento de robôs utilizando Java e a plataforma Robocode, na qual os robôs participam de batalhas em uma arena, utilizando diferentes estratégias de movimentação, identificação de adversários e disparos.

O principal objetivo do projeto é trabalhar com Git e GitHub em um ambiente de desenvolvimento colaborativo, colocando em prática o controle de versão, o compartilhamento de código, a organização das contribuições e a integração do trabalho entre os integrantes da equipe.

## Tecnologias e ferramentas

- **Java:** linguagem utilizada no desenvolvimento dos robôs.
- **Robocode:** plataforma utilizada para executar e testar os robôs.
- **Git:** ferramenta utilizada para controle de versão e acompanhamento das alterações.
- **GitHub:** plataforma utilizada para hospedagem do repositório e colaboração entre os integrantes.

## Objetivos

- Praticar o uso do Git e seus principais comandos.
- Utilizar o GitHub para compartilhar e organizar o código.
- Trabalhar de forma colaborativa em um mesmo repositório.
- Acompanhar as alterações realizadas por cada integrante.
- Integrar diferentes contribuições ao projeto.
- Compreender a importância do controle de versão no desenvolvimento de software em equipe.

## Considerações finais

O projeto tem como foco principal o aprendizado prático do desenvolvimento colaborativo, utilizando Git e GitHub como ferramentas de organização e controle de versão.

O desenvolvimento dos robôs no Robocode complementa a proposta, permitindo aplicar conceitos de programação enquanto a equipe pratica ferramentas e processos utilizados no desenvolvimento de software.
